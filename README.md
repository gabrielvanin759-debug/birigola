# Boinitim Wallpapers


## Como adicionar um wallpaper

1. Coloque a imagem dentro de `wallpapers/`.
2. Abra `script.js`.
3. Adicione um objeto ao array `wallpapers`:

```js
{
  title: "Nome do wallpaper",
  category: "Games",
  image: "wallpapers/nome-da-imagem.jpg",
  resolution: "1920×1080"
}
```
